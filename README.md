# Супермен — Стальной горизонт

3D-игра на Three.js: процедурная Земля с полной разрушаемостью и полёт на любую планету Солнечной системы.

## Запуск

Двойной клик по `start.bat` (нужен Node.js) или:

```
node server.js
```

Потом открыть http://localhost:8080. Three.js грузится с CDN, нужен интернет.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | полёт / бег |
| Пробел / C (Ctrl) | вверх / вниз |
| Shift | ускорение; держи — гиперзвук (на Земле до ~5000 км/ч, в космосе быстрее света) |
| ЛКМ | удар с рывком к цели; держи — заряженный удар; отбивает снаряды |
| ПКМ | тепловое зрение (поджигает здания, плавит) |
| F | ледяное дыхание (замораживает врагов, тушит пожары, создаёт лёд на воде/лаве) |
| Q | удар о землю (в воздухе — пике до земли с кратером) |
| E | схватить врага / вырвать скалу из земли / бросить |
| X | рентгеновское зрение (здания прозрачные, видно спрятанное) |
| Z | сверхскорость (время замедляется) |
| Tab / T / M | цель в космосе / автопилот / карта |

## Миры

- **Земля** — бесконечный рельеф, реки, горы, леса, процедурные города; смена дня и ночи (ночью горят окна). Небоскрёбы можно срезать ударом, пролететь насквозь, поджечь, обрушить. Вторжение дронов, затем босс «Титан».
- **Луна** — гравитация 1/6, кратеры, Земля в небе; кристалл спрятан под грунтом (рентген + удар о землю).
- **Меркурий** — гигантское Солнце, солнечная перегрузка (бесконечная энергия, лучи ×3), Монолит, который берёт только жар.
- **Венера** — жёлтая мгла, кислотный дождь, извергающиеся вулканы, лавовые озёра, големы; надо заморозить лаву в жерле.
- **Марс** — Олимп, долина Маринера, пылевые бури, три боевые треноги с тепловыми лучами.
- **Юпитер** — нет поверхности, слои облаков, молнии, медузы; Большое Красное Пятно затягивает вихрем.
- **Кольца Сатурна** — невесомость среди ледяных глыб, Сатурн на полнеба, гигантский астероид.
- **Уран** — ледяная равнина, алмазный дождь (собрать 25).
- **Нептун** — ураганный ветер сносит героя, ледяные шпили, босс Страж Бури.

В космосе: Солнце (пролёт рядом даёт солнечную перегрузку), пояс астероидов, кометы. Подлёт к планете — вход в атмосферу. Подъём выше атмосферы — выход на орбиту.
Прогресс (кристаллы) сохраняется в браузере.
